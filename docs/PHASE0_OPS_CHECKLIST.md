# Phase 0 — Validate operations and configure the pilot

Use this checklist before expanding beyond the 1–2 floor pilot.

**Product surfaces:** Superadmin **Hotel setup** creates the hotel (profile, types, catalogue, standards, bulk rooms, store/staff). Day-to-day room and fitted-linen tweaks use **Admin**.

## Topology and standards

- [ ] Confirm room list (each room is its own clean-linen station; floors are for routing only)
- [ ] Confirm live room list (numbers, categories, king/twin)
- [ ] Confirm linen item catalogue and units (piece-level)
- [ ] Confirm room linen standards per category × bed config
- [ ] Confirm station par levels and store opening stock
- [ ] Label any demo/estimated figures as non-official

## Observe one complete cycle

- [ ] 07:00 Supervisor confirms the occupied-room list (CSV/manual/no-PMS board today; booking/HMS link is future scope)
- [ ] Confirm every occupied room starts **Soiled / service required** on the assignment grid and clears only after the Housekeeper records service
- [ ] Supervisor assignment practice (~15 rooms/agent default, override rules)
- [ ] Cart loading confirmation at station
- [ ] Room service counts (linen in / linen out / exceptions)
- [ ] Standing guest extras are visible on the normal room round; record daily clean-in, soiled-out, partial, DND, and not-changed quantities
- [ ] Photo evidence for stains/damage/missing
- [ ] Supervisor verification walk-through
- [ ] Second-shift handover: supervisor reviews rooms marked not changed / DND and reassigns them where required
- [ ] Station soiled consolidation (prep for Phase 2)
- [ ] Store piece count and handover acknowledgement (Phase 2)
- [ ] Laundry dispatch and return matching (Phase 2)

## Accountability

- [ ] Name who enters each count (agent / porter / store)
- [ ] Name who acknowledges station→store handover (dual control)
- [ ] Define who may approve write-offs and guest-claim status changes
- [ ] Confirm no automatic guest charging from LINOS

## Evidence and privacy

- [ ] Photo retention days and archive/delete policy
- [ ] Access rules for evidence viewers
- [ ] Instruction: avoid guest faces, documents, belongings
- [ ] Confirm guest PII is not imported unless a signed business need exists
